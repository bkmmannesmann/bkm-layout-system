# Instagram-Karussells

Ein Ordner je Post. Darin liegt der Entwurf aus Claude Design, so wie er exportiert wurde.
Die Anleitung steht in [`docs/INSTAGRAM.md`](../../docs/INSTAGRAM.md).

```bash
python3 scripts/build_instagram.py social/instagram/<post>/
```

`beispiel/` ist die Referenz: sieben Folien, 1080 × 1350, nur Markenfarben und -schriften.
